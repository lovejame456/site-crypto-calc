How to Use Quant Terminal
📊
What is this tool?
A crypto strategy backtester. It replays historical price data and simulates trades using the Bollinger Bands + MACD + ATR triple-factor strategy. You adjust parameters, see how the strategy would have performed — without risking real money.
🪙
Step 1: Pick a coin
Click BTC / ETH / SOL to switch coins. By default it uses simulated 365-day data (MOCK mode). To use real market data, click the MOCK/LIVE toggle in the header — it fetches live 15-minute candles from Binance.
🎛
Step 2: Adjust parameters
Drag the sliders or type values — everything updates in real-time. Each parameter controls a different part of the strategy: MA Period = Bollinger Band width, RSI lines = when the market is oversold or overbought, ATR Multiplier = stop-loss distance, Leverage = amplify gains and losses, Initial Balance = starting capital in USD.
🔄
Step 3: Watch results update live
Every slider drag and coin switch instantly re-runs the simulation — no buttons needed. The four metric cards flash blue to confirm. The charts (equity curve + RSI) update in real-time as you adjust.
📈
Step 4: Read the results
Total Return — overall profit/loss %. Win Rate — % of profitable trades. Max Drawdown — worst peak-to-trough drop (risk gauge). Sharpe Ratio — risk-adjusted return (above 1 = good). The main chart shows the gold equity curve — if it goes up, the strategy makes money.
🧠
Strategy Logic
BUY when: price dips below Bollinger lower band (cheap) AND RSI signals oversold (panic) AND MACD histogram starts growing (momentum reversing). SELL when: price hits Bollinger upper band (expensive) OR RSI goes overbought OR ATR stop-loss triggered (price dropped too far from entry).
💡
Pro Tips
Try leverage 10x to see amplified results (and amplified risk). Try different coins — each has different volatility patterns. Click the MOCK/LIVE toggle to validate with real Binance data.
